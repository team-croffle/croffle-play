# Public Suffix List 검토 (`croffle-play.link`)

결론: **지금은 등록하지 않는다.** 팀 밖 개발자에게 publish를 열기 전에 등록한다. 아래 조건을 먼저 갖춘다.

## 왜 문제가 되나

브라우저는 "site"(등록 도메인, eTLD+1)를 보안 경계로 쓴다. 지금 `tetris.croffle-play.link`와
`arena.croffle-play.link`는 origin은 다르지만 **같은 site**다.

| 영향                                                                        | 지금                                                                                                            | PSL 등록 후                        |
| --------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 쿠키: 한 게임이 `Domain=croffle-play.link` 쿠키를 심어 다른 게임에 보냄     | 엣지에서 `Set-Cookie`를 지우지만 `document.cookie`로는 가능. 플랫폼은 게임 쿠키를 쓰지 않으므로 피해는 게임끼리 | 상위 도메인 쿠키 자체가 거부됨     |
| `SameSite` 판정: 게임 A → 게임 B 요청이 same-site                           | 게임 서버(Tier 2)가 쿠키 기반 인증을 쓰면 위험(쓰지 말라고 문서화)                                              | cross-site로 판정                  |
| 프로세스 격리(Site Isolation): 같은 site는 렌더러 프로세스를 공유할 수 있음 | 게임끼리 Spectre류 사이드 채널 격리가 약함                                                                      | 게임마다 별도 site → 별도 프로세스 |
| 저장소 분할                                                                 | 프레임 저장소는 최상위 site(플랫폼)+프레임 origin으로 분할되어 이미 게임별                                      | 변화 없음                          |

플랫폼 자체(셸·API·세션)는 다른 등록 도메인(`play.croffledev.kr`)이라 이 문제와 무관하다.

## 왜 지금은 안 하나

- 지금 게임은 팀원이 만들고 관리자 승인을 거친다. 게임끼리의 공격은 위협 모델 밖이다.
- 등록은 되돌리기 어렵다(삭제 요청도 몇 주~몇 달, 이미 배포된 브라우저에는 다음 업데이트까지 남음).
- 등록하면 `croffle-play.link` 자체에 쿠키를 둘 수 없다 — 지금 그럴 계획은 없지만 결정이 고정된다.

## 등록 전 조건 (외부 개발자 개방 전 체크리스트)

1. 도메인 만료까지 **2년 이상** 남도록 갱신(PSL 요구 사항).
2. `croffle-play.link`의 루트(`@`)에 쿠키·서비스를 두지 않는다는 결정 확인.
3. Tier 2 게임 서버가 쿠키를 쓰지 않는다는 규칙 유지(이미 `Set-Cookie` 제거).
4. PSL 저장소 PR(PRIVATE DOMAINS 섹션) + DNS TXT `_psl.croffle-play.link` → PR URL.
5. 반영 확인 후(브라우저 릴리스 주기) 외부 개방.

## 영향 범위 메모

- Let's Encrypt 등 발급 한도가 서브도메인별로 계산된다(오히려 유리).
- Cloudflare 설정(와일드카드 DNS, Cache Rule)은 바뀌지 않는다.
- 셸 CSP `frame-src https://*.croffle-play.link`는 그대로 동작한다.
